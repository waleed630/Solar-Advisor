The model grows with the data

On homes it has never seen, R² rises from 0.64 with 2 homes to 0.84 with 4, and the average error falls from 39% to 33%.

Four homes is a short curve; it updates every time a bill is added.

retrain() logs every run in models/history.csv, so this chart can be redrawn as the dataset grows toward 20 to 30 homes.
