The web app

Vue 3

Bill entry and photo upload, appliances, roof drawn on a satellite map, charts of the plan.

Express + MongoDB

Prices and tariff (editable by admin), saved plans, quote requests.

Python FastAPI

Models, retrain(), solar calculator, appliance split, bill OCR.

With the user’s consent, a new bill is checked, added to the data, and the model retrains on the spot.

Live demo here: upload a bill, show the result screen, then the Prices screen where an admin updates panel prices.
