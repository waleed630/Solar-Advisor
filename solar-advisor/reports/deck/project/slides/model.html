Below 20°C use stays flat. Every 1°C above it adds about 9% of a home’s average monthly units.

Tested by leaving one home out each time. The one-model approach fails because the 44 marla home uses about 5 times more than the others, so it cannot be guessed from small homes. The shape model works for big and small homes. Counting only the degrees above 20°C (when ACs switch on) cut the average error from 41% to 33%; retrain() tests several base temperatures and keeps the best. Both models retrain after every new bill and are replaced only if the new one scores better.
